# aprojic.github.io — AI Agent Instructions

Independent repository for Ante Projić's personal static site. The site is a single hand-written `index.html` with no framework, build step, analytics, or external runtime dependencies.

## Rules

- Preserve the privacy-first, zero-tracking design and strict Content Security Policy.
- Keep the site accessible, responsive, fast, and functional without JavaScript unless a change is explicitly approved.
- Verify professional titles, certifications, company roles, links, and other current claims from live authoritative sources before changing them.
- Do not apply Ctrl Alt Grow branding automatically; this is Ante's personal site.
- Avoid adding third-party fonts, scripts, trackers, forms, cookies, or network dependencies without explicit approval and a documented privacy/security rationale.
- Preserve unrelated changes in `index.html`. Never commit, push, or deploy without explicit instruction; use DCO sign-off for commits.

## Verification

- Validate HTML and inspect the effective CSP after changes.
- Check keyboard navigation, visible focus, reduced-motion behavior, mobile layout, and both color schemes in a real browser.
- Confirm the page makes no unintended external requests.
